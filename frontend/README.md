# Frontend

React + Vite 기반 체험 화면입니다. 쇼핑 체험, AI와 대결, 피크타임 우선 처리 시뮬레이션, 판매자 대시보드를 제공합니다.

## 실행 방법

```powershell
cd frontend
npm install
Copy-Item .env.example .env   # 필요하면 VITE_API_BASE를 실제 백엔드 주소로 수정
npm run dev
```

브라우저에서 http://localhost:5173 에 접속합니다. 모든 화면이 백엔드(`backend/`, 8000번 포트)의 API를 쓰므로 백엔드도 함께 실행해야 합니다.

## 화면과 경로

| 경로 | 화면 | 내용 |
|---|---|---|
| `/` | 시작 화면 | 왼쪽 사이트 소개, 오른쪽 체험 카드 4개. "쇼핑 체험하기"만 새 세션을 만든다 |
| `/main` | 상품 목록 | 6개 카테고리, 48개 상품 |
| `/products/:id` | 상품 상세 | 들어올 때 조회 한 건을 서버에 저장. 구매 의도 단계에 따라 비교·찜 모달이나 구매 버튼 강조 |
| `/checkout/:id` | 결제 | 결제 기록 저장 (가상 결제) |
| `/waiting`, `/result` | 결과 | 이 세션의 예측 순위와 실제 구매 상품 비교, 예측 이유(SHAP 기여도) |
| `/guess` | AI와 대결 | 실제 쇼핑 기록을 보고 산 상품을 맞히는 3라운드 게임 (사람 vs AI) |
| `/peak` | 피크타임 시뮬레이션 | 선착순과 우선 처리를 나란히 재생, 장면 결과, 100개 시간대 전체 결과 |
| `/admin` | 판매자 대시보드 | 쇼핑 중 고객의 단계별 인원, 상품별 예상 판매량, 확인해볼 점. 5초마다 갱신 |

시작 화면, 피크타임, 판매자 대시보드, AI와 대결에서는 쇼핑몰 상단바를 숨깁니다.

## 쇼핑 체험 흐름

체험 한 번이 서버의 세션 하나입니다. 세션 번호는 sessionStorage에도 저장해서 새로고침해도 이어집니다.

1. 시작 화면에서 "쇼핑 체험하기" → 새 세션 생성 (이전 세션이 결제 없이 끝났으면 서버가 닫음)
2. 상품 상세에 들어갈 때마다 조회 한 건을 저장하고, 서버가 돌려준 구매 의도 단계로 안내를 띄움
   - 고민 중: 비교 모달 / 떠나려는 중: 찜·가격 알림 모달 / 살 마음 먹음: 구매 버튼 강조
   - 같은 단계가 이어지면 모달을 다시 띄우지 않음
3. 결제 → 결제 기록 저장 → 결과 화면에서 예측과 실제 구매 비교

## 폴더 구조

```
src/
  App.jsx                 경로, 상단바 표시 여부, 단계 모달
  styles.css              쇼핑 화면 공통 스타일과 색 변수 (:root)
  data/products.js        상품 48개 (6개 카테고리 × 8개)와 이미지 경로
  context/ShoppingContext 세션 번호, 조회 기록, 구매 상품, 구매 의도 단계 상태
  api/                    백엔드 호출 (session.js, peak.js, guess.js)
  components/             상품 카드, 단계별 모달
  pages/                  시작, 상품 목록·상세, 결제, 결과, 판매자 대시보드
  peak/                   피크타임 시뮬레이션 (재생 계산, SVG 그래프, 화면)
  guess/                  AI와 대결 (라운드, 결과, 최종 화면, 점수 계산)
```

그래프는 라이브러리 없이 SVG로 그립니다.

## 색 바꾸기

- 쇼핑 화면, 판매자 대시보드, AI와 대결: `src/styles.css` 맨 위 `:root` 변수 (`--ink`, `--accent`, `--green` 등)
- 피크타임 화면: `src/peak/peak.css` 맨 위 `.peak-page` 변수
- SVG 그래프 색은 CSS 변수를 쓸 수 없어 `DashboardPage.jsx`의 `STAGES`, `PeakPage.jsx`의 `COLORS`에 따로 있습니다. 변수를 바꿀 때 같이 맞춥니다.
- 화면 너비를 다 쓰는 페이지(피크타임, 판매자 대시보드)의 양옆 여백은 `--page-gutter` 하나로 맞춥니다.

## 상품 이미지 바꾸기

사진을 `public/images/`에 상품 id 이름으로 넣고(예: `TOP-01.jpg`), `src/data/products.js`의 `PHOTOS` 목록에 파일 이름을 추가합니다. 목록에 없는 상품은 일러스트(`public/images/illust/<id>.svg`)가 나옵니다.
