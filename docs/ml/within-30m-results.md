# 조회 후 30분 내 구매 예측: 첫 실험 결과

## 무엇을 예측했나

사용자가 조회한 상품마다, 예측 시점 **이후 30분 안에**
그 상품을 구매했는지 예측했다.

입력에는 예측 시점까지의 조회 기록만 사용했다.
상품별 조회 횟수, 전체 조회 중 비율, 첫 조회 후 경과 시간,
마지막 조회 후 경과 시간의 4개 피처를 사용했다.
구매 기록은 정답을 만드는 데만 사용했다.

초기에는 구매 정답에 시간 제한이 필요하다고 판단해 30분 기준으로 실험했다.
이후 본 모델은 시간 제한 없이 구매 여부를 정답으로 사용하기로 했으므로,
이 결과는 본 모델의 성능이 아니다.

## 데이터와 모델

조회 사이 30분 이상 공백이 있으면 새 세션으로 구분했다.
각 조회 시점까지 본 상품을 후보로 사용하고,
그 시점 이후 30분 안에 구매한 후보를 정답 `1`로 표시했다.

| 구간 | 상품 행 | 구매 정답 행 |
| --- | ---: | ---: |
| 학습 | 5,103,713 | 31,596 |
| 검증 | 760,435 | 5,535 |
| 평가 | 791,102 | 4,649 |

데이터를 시간순으로 분리했고, 같은 세션이 여러 구간에 들어가지
않도록 했다. LightGBM으로 학습했으며 검증 결과를 기준으로
49번째 학습 반복의 모델을 선택했다.

## 상품별 평가

| 지표 | 검증 | 평가 |
| --- | ---: | ---: |
| 단순 기준 AP | 0.007279 | 0.005877 |
| 모델 AP | 0.025069 | 0.025314 |
| 모델 ROC-AUC | 0.713617 | 0.760726 |
| 단순 기준 Log loss | 0.043175 | 0.036054 |
| 모델 Log loss | 0.040277 | 0.032913 |

단순 기준은 모든 상품에 같은 구매 비율을 부여한 경우다.
AP는 정확도가 아니며, 구매 상품에 높은 점수를 주는 정도를
보는 지표다.

## 후보 상품 순위 평가

후보가 2개 이상이고 실제로 구매한 후보가 있는 시점에서,
모델의 1순위 상품이 구매 상품인지 확인했다.

| 지표 | 검증 | 평가 |
| --- | ---: | ---: |
| 평가한 예측 시점 | 2,501 | 2,244 |
| 무작위 선택 성공률 | 30.80% | 32.93% |
| 모델 1순위 성공률 | 63.43% | 66.47% |

이 성공률은 구매가 있었던 시점에 한정된다.
구매 자체가 발생할지를 같은 비율로 맞혔다는 뜻은 아니다.
같은 구매가 여러 예측 시점의 정답에 포함될 수도 있다.

현재는 점수로 상품 순위를 평가했으며,
구매/미구매를 결정하는 임계치는 아직 설정하지 않았다.
모델 파일과 생성 데이터는 로컬에만 보관하고 Git에는 올리지 않는다.
