# 상품별 구매 예측 모델 v1: 학습·보정·평가 결과

[v1 설계](product-purchase-v1-spec.md) 10장의 2·3단계 결과다. [학습 데이터](product-purchase-training-data.md)로 기준선과 LightGBM을 학습하고, valid에서 모델 선택·확률 보정·임계값을 정한 뒤 test를 한 번 평가했다. 코드는 `ml/product_purchase/`에 있고, 실행 방법은 [ml/README](../../ml/README.md)에 있다.

## 확정한 모델

| 항목 | 값 |
| --- | --- |
| 모델 | LightGBM, 예측 시점 가중치(`lgbm_point`), 23회 반복 |
| 입력 | 조회 행동 피처 8개 |
| 확률 보정 | 계단 중간점을 이은 isotonic 보정(`isotonic_smooth`) |
| 구매 판정 임계값 | 4.27% |

## 평가 기준

valid와 test에서는 한 사용자가 행의 약 25%를 차지한다. 행 단위 지표는 그 사용자에 대한 성능에 가까우므로, 예측 시점마다 가중치 합이 1이 되도록 한 **시점 가중 지표**를 기준으로 삼았다. 조회 1회를 같은 무게로 평가한다는 뜻이다. 과다 조회 사용자(조회 100회 이상)를 제외한 지표도 함께 확인했다.

## 1. 모델 학습과 선택 (valid)

train 42,657,643행을 샘플링 없이 모두 사용했다. train의 사용자 불균형을 다루기 위해 LightGBM을 세 가지 행 가중치로 학습했다.

- `row`: 모든 행 1
- `point`: 예측 시점마다 합 1. 사용자 영향력이 조회 수에 비례한다.
- `user`: 사용자마다 합 1. 모든 사용자를 같은 무게로 반영한다.

| 모델 | 반복 | 시점 가중 AP | 시점 가중 AUC | 과다 조회 제외 AP | 과다 조회 사용자 AP |
| --- | ---: | ---: | ---: | ---: | ---: |
| 단순 구매 비율 | - | 0.0090 | 0.500 | 0.0090 | 0.0065 |
| 로지스틱 회귀(point) | - | 0.0218 | 0.693 | 0.0231 | 0.0172 |
| LightGBM row | 301 | 0.0306 | 0.713 | 0.0325 | 0.0149 |
| **LightGBM point** | 23 | 0.0304 | 0.710 | **0.0335** | **0.0199** |
| LightGBM user | 45 | 0.0305 | 0.715 | 0.0327 | 0.0156 |

세 LightGBM의 시점 가중 AP 차이는 0.0002로 우열을 가리기 어렵다. 과다 조회 제외 AP와 과다 조회 사용자 AP가 가장 높은 `point`를 선택했다.

LightGBM point의 피처 중요도(gain)는 조회 수 63%, 마지막 조회 후 경과 시간 13%, 첫 조회 후 경과 시간 13% 순이다. `is_last_viewed`는 예측 시점에 방금 본 상품의 마지막 조회 후 경과 시간이 항상 0이라 정보가 겹쳐 거의 기여하지 않았다.

## 2. 확률 보정과 임계값 (valid)

모델 점수를 확률로 바꾸는 방식을 valid에서 비교했다. valid를 사용자 단위 5개 묶음으로 나눠, 4개 묶음으로 보정하고 나머지 1개 묶음에 적용하는 교차 보정으로 평가했다.

| 방식 | 시점 가중 Log loss | 서로 다른 확률 값 | 특징 |
| --- | ---: | ---: | --- |
| Platt | 0.04811 | 23,604 | 10~20% 구간에서 예측 12.5%, 실제 7.3%로 과대 추정 |
| isotonic | 0.04805 | 216 | 계단식이라 조회해도 확률이 바뀌지 않는 구간이 많음 |
| **isotonic_smooth** | **0.04804** | 21,320 | isotonic 계단의 중간점을 직선으로 이음 |

`isotonic_smooth`가 확률 오차가 가장 작고 확률도 연속적으로 움직여 선택했다. 최종 보정은 valid 전체로 다시 맞췄다.

임계값은 교차 보정 확률에서 시점 가중 F1이 가장 높은 4.27%로 정했다. valid(교차 보정)에서 정밀도 5.65%, 재현율 13.40%, F1 0.0795였다. valid를 보정과 임계값 결정에 함께 사용했으므로 최종 성능은 test로 판단한다.

## 3. test 평가

모델, 보정, 임계값을 확정한 뒤 test를 한 번 평가했다. 결과를 보고 다시 조정하지 않았다.

| 지표 | 시점 가중 | 과다 조회 제외(행) | 반복 조회 시점 | 첫 조회 시점 |
| --- | ---: | ---: | ---: | ---: |
| 실제 구매 비율(단순 기준 AP) | 0.92% | 1.02% | 1.36% | 0.53% |
| 평균 예측 확률 | 0.92% | 1.04% | 1.34% | 0.55% |
| AP | 0.0310 | 0.0393 | 0.0407 | 0.0053 |
| ROC-AUC | 0.700 | 0.746 | 0.734 | 0.500 |
| 정밀도 | 5.39% | 5.80% | 5.39% | - |
| 재현율 | 14.25% | 20.50% | 20.58% | 0% |
| F1 | 0.0782 | 0.0904 | 0.0854 | 0 |

시점 가중 Log loss는 0.04922, Brier score는 0.00901이다.

### 추가 평가

- **후보 순위:** 후보가 2개 이상이고 구매한 후보가 있는 12,838개 시점에서 모델의 1순위가 구매 상품인 비율은 31.69%였다. 무작위로 고르면 12.31%다.
- **사용자·상품 단위:** 318,016개 사용자·상품 쌍에서, 각 쌍이 받은 확률 중 최댓값으로 구한 AP는 0.0420이다(구매 비율 0.85%).
- **데이터 종료 영향:** 예측 월별 실제 구매 비율과 평균 예측은 5~8월에 0.90~1.02%로 가깝다. 데이터 마지막 달인 9월은 실제 0.75%, 예측 0.88%로 모델이 조금 높게 예측한다. 이후 구매를 관찰할 기간이 짧아진 영향으로 본다.

## 해석

- **확률은 믿을 수 있다.** 처음 보는 test에서도 확률 구간별 예측과 실제 구매 비율이 가깝다. 화면에 2.5%로 표시한 상품은 실제로도 2.5% 안팎의 비율로 구매된다.
- **구분력은 있지만 약하다.** AP는 단순 기준의 약 3.4배, 후보 1순위 정답률은 무작위의 약 2.6배다. 그러나 `구매 예상`으로 판정한 상품 중 실제 구매는 약 5%다. 조회 행동만으로는 구매 여부를 강하게 구분하기 어렵다.
- **조회 이력이 쌓여야 작동한다.** 첫 조회 시점에는 모든 상품의 피처가 같아 확률이 0.55% 안팎으로 동일하고 구분력이 없다(AUC 0.500). 반복 조회 시점부터 AUC 0.73으로 구분한다.
- **판정보다 확률·순위·변화가 이 모델에 맞는 출력이다.** 대부분의 확률이 1% 안팎이라 임계값 4.27%를 넘는 경우가 드물다.

## 서비스 연결 시 검토할 점

- 조회 로그를 `features.py`의 `UserViewState`에 시간순으로 넣고, 마지막 조회 시각을 예측 시점으로 사용한다. 학습 데이터가 조회 직후 시점으로 만들어졌기 때문이다.
- 모델은 상품 ID를 입력으로 쓰지 않으므로 체험용 상품 목록에도 그대로 적용할 수 있다.
- SHAP 기여도(LightGBM `pred_contrib`)는 보정 전 모델 점수를 설명한다. 보정은 단조 증가이므로 기여 방향은 확률에도 그대로 적용되지만, 기여도 합이 보정 확률과 같지는 않다.
- 체험에서는 사용자가 반드시 한 상품을 고르지만, 모델 확률은 "기록된 미래에 구매가 나타날 가능성"이라 대부분 1% 안팎이다. 예측과 실제 선택의 비교는 후보 간 순위나 평균 대비 배수로 보여주는 방식을 검토한다.
- 상품을 하나만 보고 끝낸 경우에는 모든 확률이 같으므로 이를 설명하는 화면이 필요하다.
