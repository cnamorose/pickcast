# 조회 후 24시간 내 구매 예측: 두 번째 실험 결과

이 문서는 본 모델을 만들기 전에 진행한 두 번째 실험 기록이다. 각 조회 시점 이후 24시간 안에 상품을 구매했는지를 예측했다.

본 모델의 목표는 조회 로그가 늘어날 때마다 사용자가 본 각 상품의 구매 예측 확률을 갱신하는 것이다. 구매 정답에 30분·24시간 제한을 두지 않는다. 따라서 아래 결과는 본 모델의 성능이 아니다.

## 목표와 데이터

- 사용자·상품마다 예측 시점 이후 24시간 내 구매 확률을 예측한다.
- 입력에는 예측 시점까지의 조회 기록만 사용한다.
- 후보는 사용자가 그때까지 한 번이라도 조회한 모든 상품이다.
- 구매 후에도 해당 사용자의 조회 기록을 초기화하지 않는다.
- `events.csv`의 예측 시점 10%를 정답과 무관하게 무작위 선택했다.
- 생성한 전체 상품 행: 5,967,325개 / label=1 상품 행: 10,964개
- 시간순으로 train, valid, calibration, test를 분리하고 경계에 걸친 24시간 관찰 구간은 제외했다.

24시간 기준은 구매 전 마지막 조회가 확인된 기록 중 98.2%가 1일 이내였다는 조사 결과를 바탕으로 정한 첫 실험 기준이다. 이는 모델의 구매 재현율을 뜻하지 않는다.

## 검증 결과

| 모델 | 피처 | AP | ROC-AUC | Log loss | 구매 상품 1순위 |
| --- | --- | ---: | ---: | ---: | ---: |
| v1 | 조회 횟수·비중, 첫/마지막 조회 경과 시간 | 0.021554 | 0.805218 | 0.010715 | 35.78% |
| v2 | v1 + 최근 1시간·1일 조회 수, 사용자 전체 조회 수, 후보 수 | 0.019737 | 0.847064 | 0.010147 | 33.39% |

구매 상품 1순위 평가는 후보가 2개 이상이고 실제 구매한 후보가 있는 검증 예측 시점 883개에서 측정했다. 무작위 선택은 13.82%였다. 최근 1일 피처 모델의 AP와 1순위 결과가 가장 높아 이 24시간 실험의 모델로 선택했다. 세 모델의 차이가 작으므로 우열이 확실하다고 단정하지 않는다.

## 확률 보정 및 구매 판정

- v1 모델에서 먼저 확률 보정과 임계치를 시험했다.
- 이후 선택한 최근 1일 피처 모델도 별도로 보정했다.
- 선택한 모델의 calibration 데이터에서 구매 판정 임계치는 0.3114%, 정밀도는 5.44%, 재현율은 15.30%였다.
- 이 실험의 test 데이터는 임계치를 정한 뒤 한 번 사용했다. 결과는 아래에 기록했다.
- 점수를 근거 없이 60%, 90% 같은 구매 확률로 바꾸지 않는다.

## 24시간 실험의 test 평가

최근 1일 조회 수를 추가한 5피처 모델을 선택하고, calibration 데이터에서 확률 보정과 임계치 0.3114%를 정한 뒤 test를 한 번 평가했다.

- 상품 행: 1,075,442개 / label=1 상품 행: 1,134개
- AP: 0.018636 (단순 기준 0.001054)
- ROC-AUC: 0.763716
- 구매 판정 정밀도: 5.14% / 재현율: 14.29% / F1: 0.0756
- 구매한 후보가 있는 570개 예측 시점의 1순위 정답률: 39.56% (무작위 13.40%)
- 실제 구매율: 0.1054% / 평균 예측 확률: 0.1621%

상품 순위에는 신호가 있지만, 구매/비구매 판정과 확률의 정확성은 부족하다. 1순위 정답률은 구매한 후보가 있는 시점에 한정한 값이다. 이번 test 결과로 임계치나 모델을 다시 조정하지 않는다.
